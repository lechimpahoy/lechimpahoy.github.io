YT Creations: política de privacidade

Atualizada em 23/11/2026.

O YT Creations é uma ferramenta de uso interno, que roda no computador do próprio dono dos canais. Ela serve só para enviar, agendar e editar vídeos nos canais do YouTube desse dono e para ler as estatísticas desses canais.

Que dados a ferramenta acessa

Com a autorização do dono da conta, pelo login do Google, ela acessa a YouTube Data API (envio e edição de vídeos, thumbnails e playlists) e a YouTube Analytics API (estatísticas, só leitura).

Como os dados são usados e guardados

  • Os dados ficam só no computador do dono dos canais. Nada é vendido, compartilhado com terceiros ou usado para publicidade.
  • O token de acesso fica guardado localmente e pode ser revogado a qualquer momento em myaccount.google.com/permissions.
  • O uso dos dados recebidos das APIs do Google segue a Google API Services User Data Policy, inclusive os requisitos de uso limitado. O uso das APIs do YouTube segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
